# IUAIX – Plataforma Enterprise de Infraestrutura Criativa (DaaS)

Este repositório contém a implementação da interface principal da plataforma **IUAIX**, operando no modelo *Design as a Service (DaaS)*.

O foco estratégico deste projeto é:
- Governança de Dados
- Mitigação de Riscos
- Escalabilidade B2B

## Arquitetura de Design
O projeto foi desenvolvido sob um conceito **Clean, Minimalista e Brutalista**:
- **Cores**: Centrado no branco absoluto, preto brutalista (alto contraste) e Azul Royale para destaques e ações.
- **Tipografia**: Uso da fonte *Space Grotesk* para trazer o peso e a objetividade do brutalismo atrelado à tecnologia.
- **Formas**: Bordas sólidas (hard shadows), limites demarcados e hierarquia de informação clara sem o uso de gradientes suaves ou sombras desfocadas.

## Funcionalidades Core (Dashboard)
- **Carteira de Créditos Tokenizada**: Roll-over de 90 dias e gestão por "Tokens de Complexidade".
- **Brand Vault**: Monitoramento e validação sistêmica de entregas criativas.
- **Escrow & Arbitragem**: Indicadores de projetos em andamento e retenção de pagamentos.
- **Botão S.W.A.T.**: Acionamento de emergência para recuperação de escopos em colapso.

## Stack de Tecnologia
- Next.js (App Router)
- React 18
- Tailwind CSS
- Lucide Icons (Iconografia)
- TypeScript

## Como Rodar

```bash
npm install
npm run dev
```

Acesse em `http://localhost:3000`
